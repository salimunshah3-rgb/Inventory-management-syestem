# 📊 Inventory Management System v1.0 (Excel & VBA)

An automated, user-friendly **Inventory & Transaction Management Dashboard** built in MS Excel using VBA (Visual Basic for Applications). This tool streamlines daily sale/purchase logging, automates stock calculations, and provides real-time KPI metrics.

## ✨ Key Features

- **Real-time KPI Dashboard:** Tracks Total Purchase, Total Sales, Net Profit, Inventory Quantity, and Total Inventory Value.
- **Product Master Directory:** Centralized list for item cataloging with price management and custom stock status tracking (`To Be Ordered`, `Out Of Stock`).
- **Transaction Tracker:** Interactive UserForm to quickly add daily Purchase & Sales entries.
- **Smart Date Filtering:** Instant refresh functionality based on dynamic start & end dates.
- **Automated Valuation:** Calculates live stock values dynamically.

---

## 🛠️ Tech Stack & Tools Used

- **Microsoft Excel** (Macro-Enabled `.xlsm`)
- **VBA (Visual Basic for Applications)**
- **UserForms & Custom Controls**

---

## 🚀 How to Run the Project

1. Download or clone this repository to your local machine.
2. Open the file `Inventory_Management_System.xlsm`.
3. Make sure to click **"Enable Content / Enable Macros"** on the top yellow ribbon.
4. Click on the **"Open Inventory System"** button on the sheet to start!
